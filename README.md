One line roasting my own agent.

## Entry

> My agent spent 40 minutes and 312 tool calls 'verifying' my birthday, then asked me to confirm it.

## How it works

`main.py` writes the one-line roast to `/output/entry.txt` and validates it against the gate (UTF-8, 1–140 characters, a single line). No network, no randomness — every run writes the same text.
